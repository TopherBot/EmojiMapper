# EmojiMapper

`emoji_mapper.py` is a tiny Python script that replaces certain keywords with their corresponding emojis.

## Usage
```bash
python emoji_mapper.py 'I love coffee and pizza'
```

Output:
```
I ❤️ ☕️ and 🍕
```

## Adding your own mappings
Edit the `EMOJI_MAP` dictionary in the script.
